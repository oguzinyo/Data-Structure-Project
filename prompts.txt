## Proje Teknik Özeti

### Implementasyon Detayları

| Özellik | Değer |
|---------|-------|
| Veri Yapısı | Separate Chaining Hash Table |
| Programlama Dili | C# (.NET 10.0) |
| Erişim Karmaşıklığı | O(1) ortalama |
| Collision Yönetimi | Zincirleme (Chaining) |
| Dinamik Genişleme | Evet (Load Factor: 0.75) |

### Hash Fonksiyonları

| Fonksiyon | Açıklama | Karmaşıklık |
|-----------|----------|-------------|
| HashDJB2 | Bitcoin tarzı yaygın kullanım | O(n) |
| HashFNV1a | İyi dağılım, düşük collision | O(n) |
| HashMD5Based | Sabit boyutlu output | O(n) |
| HashSimple | Basit çarpma yöntemi | O(n) |

### Test Senaryoları

1. Temel kullanım testleri (Add, Get, Remove)
2. Hash fonksiyonu karşılaştırması
3. Collision oluşturma senaryoları
4. Blokzincir işlem ağı simülasyonu
5. Büyük ölçek performans testleri (10.000+ işlem)
